# San Guo Generals Atlas · 三国武将全图鉴

Multi-language (EN / 日本語 / 中文, default English) single-file HTML sand-table of the Three Kingdoms.
Amap offline map base + rate-of-earth 10000-grid + 716 generals with Records/Romance dual-column bios.

打开方式：直接访问本仓库的 GitHub Pages 地址（默认英文，可在页面右上角切换语言）。

## 管理后台

- 国内站：https://sanguo-atlas.app.workbuddy.host/admin/
- 国际站（本仓库）：https://fanyzou99.github.io/sanguo-atlas/admin/

后台为纯前端页面，国际站经隐藏 iframe 中继到国内站域名读写云端数据库，两端共用同一套数据。
